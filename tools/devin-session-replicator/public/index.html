Devin Session Replicator

Replica los pasos de una sesión de Devin vía API, desde una interfaz web.

1 Configurar conexión

Para instancias Enterprise usa la base de tu organización (p. ej. https://tu-org.devinenterprise.com/api/v1).
Se guarda solo en tu navegador (localStorage) y se envía por cabecera al proxy. No se persiste en el servidor.

2 Subir documento (opcional)

Sube el documento del proceso (p. ej. la grabación en .docx) para adjuntarlo al prompt.

Se incluirá automáticamente en el prompt al crear la sesión.

3 Crear sesión con el prompt

Abrir sesión en el navegador ↗

4 Enviar mensajes de seguimiento

Replica los pasos: "Crea un plan para implementar este flujo", "Lo quiero implementar directamente con Appian", etc.
